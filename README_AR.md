# مراقب الشبكة (GlassWire-Linux)

برنامج رسومي ومظلم لمراقبة حركة الشبكة لكل عملية على توزيعات Debian/Ubuntu و Fedora.

## الميزات
- عرض العمليات النشطة مع اسمها ومسارها التنفيذي
- عرض سرعة التحميل/الرفع بالثانية
- ثيم داكن + خطوط عربية واضحة
- دعم RTL في الواجهة
- قابل للتوسيع بمحرك المساعد المميز عبر polkit

## التشغيل السريع
```bash
./glasswire
```

## متطلبات
- Python 3.10+
- PySide6 + pyqtgraph
- صلاحيات polkit لميزات الحظر/الرصد المميز
