# دليل التشغيل لأول مرة

## 1. تشغيل البرنامج
من القائمة: اختر "مراقب الشبكة" 
أو من الطرفية: `glasswire`

## 2. واجهة البرنامج
- تبويب "رصد الشبكة": جدول العمليات وسرعاتها
- تبويب "المحظورون": إدارة التطبيقات المحظورة
- تبويب "الإعدادات": إعدادات المحرك والواجهة

## 3. صلاحيات المساعد
للحصول على رصد أدق وحظر فعّال، سيطلب البرنامج صلاحية polkit عند أول استخدام لميزة تتطلب صلاحيات الجذر.

## 4. ملاحظات
- في وضع "صلاحيات المستخدم فقط"، سيعرض البرنامج العمليات الخاصة بك فقط
- في وضع "وضع تجريبي"، يعرض بيانات توضيحية للاختبار
- قائمة الحظر تُحفظ تلقائياً وتُعاد عند الإقلاع
