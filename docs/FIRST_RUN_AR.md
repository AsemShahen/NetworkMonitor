# دليل التشغيل لأول مرة

## 1. تشغيل البرنامج
من قائمة التطبيقات: اختر «مراقب الشبكة».
أو من الطرفية:
```bash
network-monitor
```

## 2. الواجهة
- **الرصد المباشر**: بطاقات السرعات أعلى النافذة، ثم جدول التطبيقات النشطة مع المسار الكامل، عدد الاتصالات، سرعة التنزيل/الرفع، واستهلاك المعالج.
- **الرسم البياني**: منحنيات التنزيل والرفع على محور زمني حقيقي.
- **التطبيقات المحظورة**: استعراض/إلغاء الحظر، وتصدير/استيراد قائمة الحظر.
- **الإعدادات**: فاصل التحديث (الافتراضي 30 ثانية)، إظهار العمليات الخاملة، إعادة تطبيق الحظر عند الإقلاع، وتصفير الإجماليات.

## 3. أدوات الجدول
- **البحث**: يفلتر فوراً بالاسم أو المسار.
- **حظر المحدد**: يحظر التطبيق المحدد عبر cgroup v2 + nftables بعد مصادقة polkit.
- **إلغاء حظر المحدد**: يزيل القاعدة ويعيد العمليات إلى cgroup الجذر.
- **تصدير أسماء البرامج**: يحفظ الأسماء الظاهرة في ملف نصي مفصولة بـ «، ».
- **زر التحديث**: تحديث فوري دون انتظار الفاصل الزمني.

## 4. الصلاحيات
- قراءة حركة المقابس العائدة لمستخدمك تعمل دون صلاحيات خاصة.
- أول عملية حظر تفتح نافذة مصادقة polkit (كلمة مرور المدير).
- إذا رفضت المصادقة، يبقى الرصد يعمل ولا تُضاف القاعدة.

## 5. ملاحظات مهمة
- الحظر يشمل العمليات قيد التشغيل وقت تنفيذ الحظر. إذا شغّلت التطبيق لاحقاً، استخدم «إعادة تطبيق قائمة الحظر الآن» من تبويب الإعدادات.
- إن لم تكن حزمة `iproute2` مثبتة (أمر `ss` غير متوفر) يعمل البرنامج في وضع محدود: يعرض التطبيقات ذات الاتصالات النشطة دون سرعات، مع رسالة توضيحية.
- حركة UDP لا تظهر لها سرعات لأن `ss` لا يوفّر عدّادات بايتية لها.
- قائمة الحظر والإعدادات تُحفظ تلقائياً في مجلد المنزل وتُستعاد عند الإقلاع.
