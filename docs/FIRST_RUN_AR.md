# دليل التشغيل لأول مرة

## 1. تشغيل البرنامج

من قائمة التطبيقات: اختر «مراقب الشبكة».

أو من الطرفية:

```bash
network-monitor
```

## 2. الواجهة

- **الرصد المباشر:** بطاقات السرعات أعلى النافذة، ثم جدول التطبيقات النشطة
  مع المسار الكامل، عدد الاتصالات، سرعة التنزيل/الرفع، واستهلاك المعالج.
- **الرسم البياني:** منحنيات التنزيل والرفع على محور زمني حقيقي، مع وسيلة
  إيضاح للون كل منحنى.
- **الاستهلاك:** بطاقات إجمالي الشهر، ثم جدول قابل للبحث ومخطط يومي منفصل.
  يمكن تصدير الجدول إلى CSV أو تصفير إجماليات الشهر.
- **الأمان والتهديدات:** بطاقات الخطورة، جدول النتائج، لوحة الأدلة، وجدول
  سمعة عناوين IP. الفحوص المحلية تعمل دون اتصال.
- **التطبيقات المحظورة:** استعراض/إلغاء الحظر، وتصدير/استيراد قائمة الحظر.
- **الإعدادات:** اللغة (الإنجليزية افتراضيًا أو العربية)، الثيم، فاصل
  التحديث (الافتراضي 30 ثانية)، إظهار العمليات الخاملة، إعادة تطبيق الحظر
  عند الإقلاع، الاحتفاظ بالاستهلاك، والجامع الخلفي.

## 3. أدوات الجدول

- **البحث:** يفلتر فورًا بالاسم أو المسار.
- **حظر المحدد:** يحظر التطبيق المحدد عبر cgroup v2 + nftables بعد مصادقة
  polkit.
- **إلغاء حظر المحدد:** يزيل القاعدة ويعيد العمليات إلى cgroup الجذر.
- **تصدير أسماء البرامج:** يحفظ الأسماء الظاهرة في ملف نصي مفصولة بـ«، ».
- **زر التحديث:** تحديث فوري دون انتظار الفاصل الزمني.

## 4. الاستهلاك والجامع الخلفي

- تُحفظ إحصاءات الاستهلاك الشهرية واليومية في
  `~/.local/share/network-monitor/usage.db`.
- تُحسب الإحصاءات أثناء تشغيل البرنامج، أو باستمرار عند تفعيل **الجمع في
  الخلفية** من الإعدادات.
- الجامع خدمة systemd للمستخدم، ولا يحتاج صلاحيات root.
- إذا لم توجد جلسة systemd للمستخدم، يظل الرصد والاستهلاك يعملان أثناء فتح
  التطبيق فقط، وتظهر رسالة توضيحية في الإعدادات.
- زر **تصدير CSV** يحفظ جدول الشهر الحالي، وزر **تصفير** يبدأ الشهر من جديد.

## 5. الأمان والتهديدات

- **الفحوص المحلية** تكتشف:
  - الملفات التنفيذية التي تعمل من مسارات مؤقتة مثل `/tmp`.
  - الاتصالات بمنافذ تعدين شائعة.
  - ارتفاع الرفع بشكل غير معتاد مقارنة بخط الأساس للتطبيق.
- **الفحص الاختياري** يستخدم مفاتيح API الخاصة بك:
  - AbuseIPDB أو VirusTotal لسمعة عناوين IP.
  - MalwareBazaar أو VirusTotal لبصمة SHA-256 للملف التنفيذي.
- أدخل المفاتيح من **الإعدادات ← الأمان والتهديدات**، وفعّل الفحص التلقائي
  فقط إذا كنت تقبل إرسال العنوان أو البصمة إلى المزوّد.
- النتائج تُخزّن محليًا في `security.db`، ويمكن تحديثها يدويًا من قائمة
  السياق.
- لا يوجد تتبّع، ولا تُرسل البيانات تلقائيًا دون تفعيل الفحص الخارجي.
- حظر عنوان IP أو تطبيق يتم بعد تأكيد صريح، ويستخدم المساعد المميز نفسه.

## 6. الصلاحيات

- قراءة حركة المقابس العائدة لمستخدمك تعمل دون صلاحيات خاصة.
- أول عملية حظر تفتح نافذة مصادقة polkit (كلمة مرور المدير).
- إذا رفضت المصادقة، يبقى الرصد يعمل ولا تُضاف القاعدة.
- الحزم الرسمية على Fedora/Debian تستخدم PySide6 وpyqtgraph وpyroute2
  وNumPy من النظام؛ لا تحتاج تثبيت حزم Python إضافية.

## 7. ملاحظات مهمة

- الحظر يشمل العمليات قيد التشغيل وقت تنفيذ الحظر. إذا شغّلت التطبيق لاحقًا،
  استخدم «إعادة تطبيق قائمة الحظر الآن» من تبويب الإعدادات.
- المحرك الأساسي هو Netlink عبر `pyroute2` (مرفق في حزم الإصدار). إن لم
  يتوفر، يجرّب البرنامج `ss`، ثم يعمل في وضع محدود عبر `/proc/net`: يعرض
  التطبيقات ذات الاتصالات النشطة دون سرعات مع رسالة توضيحية.
- حركة UDP/QUIC قد تظهر بلا سرعة لأن النواة لا توفر عدّادات بايتية موثوقة
  لها عبر sock_diag؛ تظهر «السرعة غير متاحة» بدل `0 B/s`.
- قائمة الحظر والإعدادات تُحفظ تلقائيًا في مجلد المنزل وتُستعاد عند الإقلاع.
